# Integrasi Audit Keamanan

Panduan ini membahas penggunaan alat bantu pemeriksaan keamanan secara terkendali. Tujuannya membantu tim menemukan hal yang perlu diperiksa lebih lanjut, bukan memberi jaminan bahwa aplikasi bebas masalah. Saat melaporkan hasil kepada pimpinan, jelaskan cakupan yang diperiksa, arti temuan bagi layanan atau data, keterbatasan pemeriksaan, dan tindak lanjut sebelum menyertakan rincian alat.

Referensi: https://github.com/cloudflare/security-audit-skill

Instalasi dan eksekusi memerlukan persetujuan serta sandbox sesuai persyaratan skill. Jangan menjalankan otomatis di produksi. Laporan audit disimpan di repository aplikasi yang memiliki pembatasan akses, lalu ringkas hasil terverifikasi pada dokumen ISO 28–31.
