# Integrasi Audit Keamanan

Referensi: https://github.com/cloudflare/security-audit-skill

Instalasi dan eksekusi memerlukan persetujuan serta sandbox sesuai persyaratan skill. Jangan menjalankan otomatis di produksi. Laporan audit disimpan di repository aplikasi yang memiliki pembatasan akses, lalu ringkas hasil terverifikasi pada dokumen ISO 28–31.
